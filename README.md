# 🌾 NusaTani — Masa Depan Pertanian Digital Indonesia

Platform data pertanian, AI, dan ekosistem digital untuk membantu petani Indonesia berkembang.

## ✨ Features

- **Modern Landing Page** — Desain profesional, responsif, mobile-first
- **Dark Mode** — Support tema gelap otomatis
- **Smooth Animations** — Animasi halus dengan CSS dan JS
- **Counter Animation** — Statistik dengan animasi angka
- **Glassmorphism UI** — Desain modern dengan efek blur dan transparency
- **SEO Friendly** — Semantic HTML dan meta tags optimal
- **Performa Tinggi** — Tanpa framework berat, loading super cepat

## 🚀 Tech Stack

- HTML5 Semantic
- CSS3 (Custom Properties, Grid, Flexbox, Animations)
- Vanilla JavaScript (ES6+)
- Google Fonts (Inter, Plus Jakarta Sans)
- Mobile-first Responsive Design

## 📁 Structure

```
NusaTani1/
├── index.html      # Main HTML file
├── styles.css      # Complete stylesheet
├── script.js       # Animations & interactivity
└── README.md       # Documentation
```

## 🖥️ How to Run

Simply open `index.html` in any modern browser, or serve with any static server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .
```
